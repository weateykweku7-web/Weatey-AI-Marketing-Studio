# Weatey AI Marketing Studio

Weatey AI Marketing Studio is a modern web application designed for marketers, creators, and business owners to instantly generate high-converting marketing copy.

## ✨ Features
- **Ad Copy Generator**: Create compelling ad copy for Facebook, Instagram, Google, and TikTok.
- **Social Media Captions**: Generate platform-specific posts with targeted hashtags.
- **Email Campaign Generator**: Write promotional emails, welcome sequences, and cold outreach.
- **SEO Blog Outlines**: Plan out SEO-optimized blog posts, titles, and meta descriptions.
- **Persistent History**: Automatically saves all generated assets to browser LocalStorage.

## 🚀 Quick Start
1. Place `index.html`, `style.css`, and `script.js` in the same directory.
2. Open `index.html` in any web browser or via a local static server (e.g., VS Code Live Server).
